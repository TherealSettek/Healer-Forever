Party bars preview

The button shows the next buff it will cast, with a count when several are missing. Left-click casts one buff. Right-click casts the group version (Greater / Prayer / Brilliance / Gift) on that class.
Keybind demo: press X. One press = one cast, walking tank, other healers, DPS, then you.
Notes: Spell names are from vanilla memory and must be checked against the WoW Forever spellbook. The addon will only show spells the character actually knows (greyed here: Sanctuary and Divine Spirit simulate "not in your spellbook"). A WoW addon cannot cast several spells from one click or key press: one cast per click is a restriction of the secure action system, so the button advances to the next buff after each cast. The group version buttons use SecureActionButton attributes spell1 (left) and spell2 (right) re-assigned out of combat after each aura change. Icons here are emulated; the addon would use the spell textures via C_Spell.GetSpellTexture.
