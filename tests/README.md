# HealerForever tests

## Run

```
./run-tests.sh            # luacheck (if installed) + whole suite
./run-tests.sh units      # only test files whose name contains "units"
luajit tests/run.lua      # suite only
```

Requirements: `brew install luajit` (or any Lua 5.1 interpreter). Optional lint:
`brew install luarocks && luarocks --lua-dir=$(brew --prefix luajit) --lua-version 5.1 install luacheck`
(installs to `~/.luarocks/bin`, which `run-tests.sh` adds to PATH). Lint is skipped with a warning if luacheck or
the repo `.luacheckrc` is missing. Exit code is nonzero if lint or any test fails. No test dependencies: the
framework is `framework.lua` (describe / it / expect / assertEquals ...). Set `HF_TRACE=1` for Lua tracebacks.

## What CANNOT be tested outside the game

* Real secret-value semantics (Blizzard's 12.0 restrictions): the mock only approximates them with
  tables that raise on arithmetic/comparison/concatenation/indexing.
* Real secure click-casting: whether Blizzard accepts the attributes, `[@unit,dead]` macro behaviour, override bindings, Cmd/Meta clicks on macOS.
* Taint, protected-frame rules beyond what the mock tracks, secure handler snippets, state drivers.
* Visuals: layout, textures, colours, fonts, animations, tooltips, minimap pin placement, performance.
* Real event ordering/payloads and real Blizzard frame behaviour (PartyFrame hiding, Settings panel).

## In-game manual test checklist

1. `/console scriptErrors 1` and install BugSack/BugGrabber; `/reload` and confirm no errors.
2. Join a party (1-4 members, also with pets); frames appear, update HP/power/auras, and shrink/grow on roster changes.
3. Click-casting: test every binding (Left/Right/Middle/Mouse4/5, with Shift, Ctrl, Alt, and Cmd/Meta on Mac) on yourself and a party member; confirm the right spell/target/menu.
4. Resurrection on dead: let a member die (or kill one), click them with each spell binding, and confirm only the res spell (Redemption/Resurrection/Ancestral Spirit/Rebirth) is cast, in and out of combat. Resurrect and confirm the normal spell is cast again.
5. Combat test: enter combat, a member dies/resurrects/joins/leaves, change options. No "action blocked" messages, bindings keep working; changes apply after combat.
6. Preset switching (`/hf preset 2`, options UI): the missing-buff button shows the correct buff per class; clicking casts it; it hides when the buff is present with more than 60s left.
7. Missing buff button: let the buff fall off / expire under 60 s; check the timer text formats (9.9, 59, 5m, 1h).
8. Hide Blizzard party frames option: toggle on/off, also after `/reload` and in combat.
9. Minimap button: drag it around the minimap, left/right click, hide/show it via options, position persists after `/reload`.
10. Minimap party pins: visible outdoors in class colours; an X in class colour for a dead member; pins stick to the edge when far away; test rotating minimap on and off; inside a dungeon/instance pins hide (no positions) and no errors.
11. Lock/unlock frames and drag; `/hf` with no args, `/hf help`, and garbage input.
12. Roles and self: in a party with a tank, a healer and a DPS of the same class, confirm each member's missing-buff button shows the buff the preset assigns to that role (e.g. 5-man: Paladin tank gets Might, Paladin healer gets Wisdom); set a Self buff and confirm only you get it; override a member's role in Buff Presets > Group roles (also in combat: it applies when combat ends); role icons show on the frames (atlas or fallback texture).
13. Click-Casting editor: toggle Shift/Ctrl/Alt/Cmd and confirm the rows show that combo; drag a spell onto a row, clear it with X; Unit menu is only offered on plain Right; click a combo chip to jump to it; assign in combat and confirm it applies after combat.
14. Lock badge: padlock shows on the minimap button while frames are locked; right-click, `/hf lock`/`unlock`, and the options checkbox all keep it in sync, including in combat.
15. Spellbook: Class Spells and the click-cast Pick menu list your real spells and talent spells (Light's Vigil, Oath of Light on Forever Paladins); drag from the pane to a binding row; learn/unlearn a talent and confirm the list updates after a moment.
16. Missing-buff button: visible (pulsing) on every member lacking their buff, including solo; grey if you do not know the spell; `/hf debug buffs` explains every hidden button.
17. Role buffs and smart button: add a tank-only oath in Buff Presets > Role buffs; only the tank gets the second button; bind a key (Esc > Keybindings > AddOns > Healer Forever) and confirm repeated presses cast tank oath, then tank/healer/DPS blessings, then yourself; nothing changes in combat.
18. Hover a party member with several debuffs: the tooltip lists all of them (type, stacks, time left), dispellable ones first with a marker; toggle "Also list buffs" in Buffs & Debuffs; in combat the list is either shown or "Debuffs hidden by the game during combat".
19. Profiles: on a character that never ran the addon, settings are seeded from your old account-wide settings (`/hf profile` says so); change something, `/reload`, log another character and confirm it has its own settings; `/hf copyaccount confirm` and `/hf reset` affect only the current character.
20a. Strict casting: stand a party member out of sight or range and click/bind a spell on them (and press the smart/tank keys): nothing is cast on you or your target; the buff button greys out with "Out of range" and re-arms when they return.
20. Errors and taint: `/hf errors` after normal play is empty (or lists what broke, with counts); `/hf errors clear` empties it; with "Hide default Blizzard party frames" on, entering and leaving combat and joining/leaving the party causes no "action blocked" messages.
21. Delete `HealerForeverCharDB` (and `HealerForeverDB`) from WTF SavedVariables (or corrupt it) and confirm the addon starts with defaults and no errors.
