# HealerForever tests

## Run

```
./run-tests.sh            # luacheck (if installed) + whole suite
./run-tests.sh units      # only test files whose name contains "units"
luajit tests/run.lua      # suite only
```

Requirements: `brew install luajit` (or any Lua 5.1 interpreter). Optional lint:
`brew install luarocks && luarocks --lua-dir=$(brew --prefix luajit) --lua-version 5.1 install luacheck`
(installs to `~/.luarocks/bin`, which `run-tests.sh` adds to PATH). Lint is skipped with a warning if luacheck or
the repo `.luacheckrc` is missing. Exit code is nonzero if lint or any test fails. No test dependencies: the
framework is `framework.lua` (describe / it / expect / assertEquals ...). Set `HF_TRACE=1` for Lua tracebacks.

Party golden snapshot: `HF_UPDATE_GOLDEN=1 ./run-tests.sh party_golden` rewrites `fixtures/party-golden-0.10.1.lua` from the
current tree (only for an intended party change; review the diff, every changed line is a visible party change).

## What CANNOT be tested outside the game

* Real secret-value semantics (Blizzard's 12.0 restrictions): the mock only approximates them with
  tables that raise on arithmetic/comparison/concatenation/indexing.
* Real secure click-casting: whether Blizzard accepts the attributes, `[@unit,dead]` macro behaviour, override bindings, Cmd/Meta clicks on macOS.
* Taint, protected-frame rules beyond what the mock tracks, secure handler snippets, state drivers.
* Visuals: layout, textures, colours, fonts, animations, tooltips, minimap pin placement, performance.
* Real event ordering/payloads and real Blizzard frame behaviour (PartyFrame hiding, Settings panel).
